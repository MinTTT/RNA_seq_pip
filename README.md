* RNA seq
* Deep seq

### RNA seq

### RNA seq

#### run pipeline
`miniBac-seq_pipeline.sh` is the script for running the pipeline, which will run `miniBac-seq_raw_data_process_clean_demix_20250401.py` first, cleaning the raw data, trime the adapter, demultiplexing data (if necessary), and then run `miniBac-seq_pip_20250105.py` for alignment, counting, and differential expression analysis.
```shell
$ bash miniBac-seq_pipeline.sh -i <raw_data_dir> -g <gff_file> -f <fasta_file> -o <clean_data_dir> -p <out_put_dir> [options]
```
The options for `miniBac-seq_pipeline.sh` are:
* `-i`: the directory of raw data, which should be in the format of `sample_R1.fastq.gz` and `sample_R2.fastq.gz`
* `-g`: the gff file for annotation
* `-f`: the fasta file for reference genome
* `-o`: the directory for clean data, which will be generated by `miniBac-seq_raw_data_process_clean_demix_20250401.py`
* `-p`: the directory for output, which will be generated by `miniBac-seq_pip_20250105.py`
* `-r`, `--run-pipeline`: Run pipeline without prompts

### trimmed adapter

```shell
cutadapt -q 20,20 --minimum-length 100:100 --max-n 3 --pair-filter=any -o "${sample}"_QF_R1.fastq.gz -p "${sample}"_QF_R2.fastq.gz "${sample}"_R1.fastq.gz "${sample}"_R2.fastq.gz > "${sample}"_logs/QF.log

# Demultiplexing /////////////////////////////////////////////////////////////
# when the library quality is high, say, each adaptor can be found strictly anchored at the 5' of R1
cutadapt --pair-filter=any --no-indels --minimum-length 20 --times 1 -e 0.15 --overlap 7 -g file:adaptor_R1.fasta -A file:adaptor_R2.fasta -o end5-{name}.R1.fastq.gz -p end5-{name}.R2.fastq.gz "${sample}"_QF_R1.fastq.gz "${sample}"_QF_R2.fastq.gz > "${sample}"_logs/demultiplexing.log

```
